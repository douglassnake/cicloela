# CicloEla

MVP de aplicativo web instalável (PWA) para acompanhamento privado do ciclo menstrual, humor e bem-estar.

## Recursos

- fluxo menstrual
- humor
- energia
- dor/cólica
- sono
- sintomas e sinais
- anotações
- calendário com previsão aproximada
- insights dos últimos 30 dias
- backup e restauração em JSON
- funcionamento offline
- dados salvos apenas no navegador

## Privacidade

O GitHub hospeda somente o código. Os registros pessoais ficam no localStorage do navegador nesta versão.

## Aviso

As previsões são estimativas. O CicloEla não substitui avaliação médica, diagnóstico ou método contraceptivo.
